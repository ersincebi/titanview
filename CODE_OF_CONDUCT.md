# Code of Conduct

TitanView follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good faith, welcome newcomers, and keep discussions about the work.
Harassment, personal attacks and discriminatory language are not tolerated in issues, pull requests or any project space.

Report unacceptable behaviour privately through GitHub's
[private reporting](https://github.com/ersincebi/titanview/security) or by contacting the maintainer
([@ersincebi](https://github.com/ersincebi)). Reports are handled confidentially.
